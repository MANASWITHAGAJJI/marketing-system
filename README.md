# Market Auto — Marketing Automation System

A responsive frontend-only marketing CRM demonstration built with HTML5, CSS3 and vanilla JavaScript.

## Run the project
1. Download and extract the ZIP.
2. Open the `marketing-automation-system` folder.
3. Double-click `index.html`, or open the folder in VS Code and use the Live Server extension.

No database, build tools or server are required.

## Features
- Dashboard with sample campaign and subscriber statistics
- Campaign create, edit, delete, search and status filter
- Email template creation, preview and deletion
- Subscriber creation, search, status changes, deletion and CSV export
- Campaign analytics and CSV report export
- Simulated automation workflow creation, pause/activate and deletion
- Landing page draft creation and publish/unpublish controls
- Responsive sidebar navigation and mobile layout
- Dark mode
- Browser `localStorage` persistence

## Notes
This is a frontend-only internship project. Campaign sending, open/click metrics, conversions, and automation execution are simulated. Data is stored in the browser's local storage and is not synchronized between devices.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — data, interactions and local storage
